# SKILL: DATA VISUALIZATION & CHARTING (skill-data-visualization.md)

> **File Location:** `skills/02-frontend-ui/skill-data-visualization.md`  
> **Role Definition:** Data Visualization Engineer & Dashboard Architect  
> **Core Mission:** Build responsive, color-blind accessible, and interactive analytical charts.  
> **Category:** Frontend, UI/UX & Design Standards  
> **Standard Compliance:** AIMASTER Architectural OS Model

---

## 1. CORE PRINCIPLES & DOMAIN STANDARDS

### 1. RESPONSIVE DASHBOARD LAYOUTS
- Chart containers must be fluid and responsive, listening to container width changes without layout thrashing.
- Handle empty, zero-data, and high-volume (10,000+ datapoint) states gracefully using data downsampling or canvas rendering.

---

### 2. ACCESSIBILITY & COLOR BLIND SAFETY
- Never communicate critical analytical insights exclusively through color. Combine colors with patterns, line styles, and numerical labels.
- Provide accessible textual data tables as alternative representations for screen readers.
