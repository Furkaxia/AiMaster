## 1. CORE PRINCIPLES & DOMAIN STANDARDS

### 1. README STRUCTURE SPECIFICATION
Every project README must follow the clean 4-part hierarchy:
1. **Project Pitch & Overview:** 2 clear sentences describing core value proposition and solved problems.
2. **Tech Stack & Badges:** Primary technologies, runtimes, and dependencies.
3. **Quickstart / Getting Started:** Exact terminal commands for cloning, installing, and configuring environment variables (`.env.example`).
4. **Scripts & Workflows:** Dev server, testing, linting, and production build commands.

---

### 2. IN-CODE JSDOC / DOCSTRING SPECIFICATION
- Document non-obvious algorithms, complex math formulas, and public export boundaries using standard JSDoc or Python docstrings.
