## 1. CORE PRINCIPLES & DOMAIN STANDARDS

### 1. CORE PATTERNS (CREATIONAL, STRUCTURAL, BEHAVIORAL)
- **Factory / Strategy:** Use Strategy patterns to replace sprawling `switch/case` blocks handling dynamic business algorithms.
- **Adapter / Facade:** Wrap complex third-party SDKs behind uniform domain adapters to insulate core application logic.
- **Observer / Pub-Sub:** Decouple state producers from consumers for non-blocking asynchronous event distribution.

---

### 2. PRAGMATIC APPLICATION
- Patterns are solutions to recurring problems, not mandatory boilerplate. Never introduce an AbstractFactory or Proxy when a plain function suffices.
