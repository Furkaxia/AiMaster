## 1. CORE PRINCIPLES & DOMAIN STANDARDS

### 1. MODERN IDIOMS & IMMUTABILITY
- Favor immutability: Prefer pure functions, `const`, object spread, and modern functional pipelines (`map`, `filter`, `reduce`) over mutable in-place mutations.
- Leverage modern language features (optional chaining `?.`, nullish coalescing `??`, destructuring, pattern matching).

---

### 2. SELF-DOCUMENTING EXPRESSIVENESS
- Write code that reads like well-crafted prose. Choose intention-revealing function and variable names (`isSubscriptionActive` over `flag`).
- Eliminate obsolete paradigms (legacy `var`, raw callback pyramids, verbose `for(var i=0...)` loops).
