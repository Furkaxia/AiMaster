## 1. CORE PRINCIPLES & DOMAIN STANDARDS

### 1. RAW CONCEPT COMPILATION PROTOCOL
When an open-ended request arrives ("build an e-commerce dashboard"), structure it into 4 formal sections before execution:
1. **Scope & Objectives:** Exact capabilities and system boundaries.
2. **Tech Stack & Libraries:** Specific tools, zero duplicate packages.
3. **User Flow & Entity Model:** State progression, data models, and API contracts.
4. **Acceptance Criteria:** Unambiguous boolean checklist for definition of done.

---

### 2. ANTI-AMBIGUITY DEFENSE
- Clarify ambiguous requirements upfront using maximum 3-5 targeted bullet points.
