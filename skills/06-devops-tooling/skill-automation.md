## 1. CORE PRINCIPLES & DOMAIN STANDARDS

### 1. RESOURCE OPTIMIZATION IN HEADLESS BROWSERS
- Abort unnecessary asset requests (images, web fonts, advertising trackers) via request interception to accelerate scraping throughput by 300%.
- Run headless instances with lightweight viewports and disable GPU emulation when unneeded.

---

### 2. ANTI-BOT DEFENSE & STEALTH
- Randomize user-agent headers and viewport dimensions. Emulate natural human cursor delays and keystroke intervals.
- Never flood target host domains: Enforce polite concurrency limits and delay intervals.
