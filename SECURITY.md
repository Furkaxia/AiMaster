# GÜVENLİK POLİTİKASI (SECURITY POLICY)

AIMASTER, yapay zeka ajanlarının güvenliğini en üst öncelik olarak kabul eder.

## 🛡️ Temel Güvenlik İlkeleri

1. **Sıfır Hardcode Bilgisi:** Hiçbir şablon veya skill dosyası gerçek API anahtarı, şifre, gizli anahtar veya hassas veri barındırmaz.
2. **Yıkıcı Eylem Güvenliği:** Ajanın dosya silme, veritabanı boşaltma veya canlıya kontrolsüz deploy etmesini engelleyen `RulesAI.md` Bölüm 4 onay bariyerleri asla gevşetilemez.
3. **Zafiyet Bildirimi:** Eğer sistem kurallarında bir bypass, jailbreak veya güvenlik açığı tespit ederseniz, lütfen GitHub Issues üzerinden public paylaşmak yerine sorumlu bildirimde bulunun.
